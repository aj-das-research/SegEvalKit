# About

SegEvalKit is an open-source library for evaluating volumetric medical image segmentation, developed by Abhijit Das.
Projects routinely re-implement Dice and Hausdorff distance slightly differently, rarely report how empty masks were
handled and rarely go beyond a mean Dice. SegEvalKit collects the recommended metrics, makes their conventions
explicit and tested, and adds the statistics and figures that turn per-case numbers into defensible conclusions.
