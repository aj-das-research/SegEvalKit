# Citation

If SegEvalKit helps your work, please cite it:

```bibtex
@software{das2026segevalkit,
  title  = {SegEvalKit: Holistic Evaluation of Volumetric Medical Image Segmentation},
  author = {Das, Abhijit},
  year   = {2026},
  url    = {https://github.com/aj-das-research/SegEvalKit}
}
```

Please also cite the papers of the metrics you report (listed on each [metric page](../metrics/index.md)) and the
recommendations behind the library:

- Maier-Hein L, Reinke A, Godau P, et al. Metrics reloaded: recommendations for image analysis validation.
  *Nature Methods* 21, 195–212 (2024).
- Reinke A, Tizabi MD, Baumgartner M, et al. Understanding metric-related pitfalls in image analysis validation.
  *Nature Methods* 21, 182–194 (2024).
- Taha AA, Hanbury A. Metrics for evaluating 3D medical image segmentation: analysis, selection, and tool.
  *BMC Medical Imaging* 15, 29 (2015).
